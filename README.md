# world.execute(me); · live

把 [MisakaZentai/world-execute-me-dsh-pv](https://github.com/MisakaZentai/world-execute-me-dsh-pv) 从
Python + PIL + Playwright 的逐帧渲染管线，移植成**浏览器里实时运行**的版本。

原项目每帧都是歌曲时间 t 的纯函数；这个移植把同一套绘制逻辑搬进 Canvas 2D 与真 HTML/CSS，
由音频时间轴驱动，**不再需要预渲染任何一帧**。整片 211.872 秒已经全部移植完成。

在线：https://lingcat521.github.io/world-execute-me-live/

## 怎么验收的

有一台 node 无头渲染器，可以把任意时刻渲染成 PNG 并与参考成片同刻抽帧做逐像素比对。
三条容易踩的坑（详细说明见仓库外的 pvport/HANDOFF.md）：

1. **参考帧必须剥掉 PNG 里的色彩管理块再解码。** refall/*.png 带 gAMA=0.45455 / cHRM / cICP，
   skia 解码时会应用它们，把参考暗部压暗约 6 个灰阶（PIL 与浏览器不会）。不剥的话，
   全片每个分数都会被冤枉 4~7 分（修之前算出 10.55/9.05，修完是 5.46/3.76）。
2. **同一帧只渲染一遍。** 在一个进程里连续渲染多个时刻，会被跨帧缓存状态污染。
3. **每个时刻单独起一个进程**，并且渲染进程要有内存上限与墙钟上限。
